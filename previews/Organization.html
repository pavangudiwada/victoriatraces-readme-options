Each database has open-source single-node and cluster versions under Apache 2.0. They can be deployed independently. VictoriaTraces is a work in progress: review its compatibility notice and release notes before adopting or upgrading it.

Build around your existing tools

  • Collect: use vmagent and Prometheus for metrics, supported log collectors for logs, and OpenTelemetry for traces.
  • Explore: use each product's built-in UI, or connect Grafana through the metrics integration, VictoriaLogs data source, and Jaeger-compatible trace integration.
  • Operate: use the VictoriaMetrics Operator, Helm charts, vmauth, and vmalert.
